# ADR 0005: remote authentication

## Status

Accepted for M4.

## Decision

Remote clients use opaque bearer tokens generated by erka. SQLite stores only a
SHA-256 hash, a display name, explicit scopes, creation time, and revocation
time. Token comparison is constant-time. TLS terminates either in erka or at an
explicitly trusted reverse proxy; forwarded identity headers never authenticate
a request.

## Consequences

The single-user server still has explicit, revocable identity. Browser-cookie
authentication and multi-user authorization are outside M4.
